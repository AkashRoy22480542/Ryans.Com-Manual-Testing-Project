📌 Project Overview

This project focuses on performing real-world Manual Software Testing on the Ryans.com platform — one of the leading IT E-commerce & Computer Retail Platforms in Bangladesh.

🔗 Website Under Test:
https://www.ryans.com/

The primary goal of this project was to evaluate the system’s:

Functional behavior
Input validation
User interface consistency
Security-oriented validation
Error handling
Usability
Overall software quality

The project was conducted following a professional Software Testing Life Cycle (STLC) workflow using industry-standard QA documentation practices.

🎯 Project Objectives

The main objectives of this project were:

✅ Validate core functionalities
✅ Identify real-world bugs
✅ Verify input validation mechanisms
✅ Analyze usability & UI behavior
✅ Perform negative & security-oriented testing
✅ Practice professional QA documentation
✅ Improve analytical testing skills
✅ Simulate real-world SQA workflow
